## 2. Scientific Purpose
CalculateContamination estimates the fraction of reads in a sequenced tumor sample that originate from cross-sample contamination. Using pileup summaries previously generated by GetPileupSummaries, the tool applies a binomial mixture model via maximum likelihood estimation (MLE) over germline variant sites. The resulting contamination fraction estimate and per-segment minor allele fractions are consumed by FilterMutectCalls to remove contamination artifacts from somatic variant calls.

## 3. Operating Modes
- **Tumor-Only Mode** (default): Only the tumor pileup summary is provided. Less accurate but always available.
- **Matched Normal Mode** (preferred): Both tumor and matched normal pileup summaries are provided. The wrapper detects the mode automatically based on whether `matched.normal.input` is supplied.

## 5. Wrapper Script Architecture (gatk_calculate_contamination_wrapper.py)

### Design Principles
- Written in Python 3 using argparse for parameter parsing
- Auto-detects operating mode (tumor-only vs matched normal) based on presence of matched.normal.input
- Resolves GATK executable via: (1) GATK_PATH env var, (2) 'gatk' on PATH, (3) common fallback paths including /gatk/gatk for Docker
- Validates all input files exist and are non-empty before invoking GATK
- Auto-creates parent directories for output files
- Streams GATK stdout/stderr to GenePattern log
- Reports output file paths, sizes, header lines, and first data rows
- Propagates GATK exit codes faithfully

### Command Structure
```
python <libdir>gatk_calculate_contamination_wrapper.py \
    --tumor-pileup-input <tumor.pileup.input> \
    --output <output> \
    [--matched-normal-input <matched.normal.input>] \
    [--tumor-segmentation-output <tumor.segmentation.output>] \
    [--arguments-file <arguments.file>]
```

The wrapper builds the GATK invocation as:
```
gatk CalculateContamination \
    -I tumor.table \
    -O contamination.table \
    [-matched normal.table] \
    [--tumor-segmentation segments.table] \
    [--arguments_file extra_args.txt]
```

## 6. Input/Output Specification

### Inputs
- **tumor.pileup.input**: .table TSV from GetPileupSummaries (columns: contig, position, ref_count, alt_count, allele_frequency, other_alt_count)
- **matched.normal.input**: .table TSV from GetPileupSummaries on matched normal sample (same format)
- **arguments.file**: Plain text file, one GATK argument per line

### Outputs
- **contamination.table** (named by `output` parameter): TSV with columns sample, contamination, error
- **tumor segments table** (named by `tumor.segmentation.output` parameter): TSV with columns contig, start, end, minor_allele_fraction

## 11. Validation Strategy
1. Confirm tumor.pileup.input exists and is non-empty
2. If matched.normal.input provided, confirm it exists and is non-empty
3. If arguments.file provided, confirm it exists
4. Verify GATK is accessible in the Docker environment
5. Confirm output files are produced with non-zero size after execution
6. Log header and first data row of each output for user feedback

## 12. Testing Approach
- **Tumor-only**: Run with tumor_pileup_summary.table only
- **Matched normal**: Run with both tumor_pileup_summary.table and normal_pileup_summary.table
- **With segmentation**: Confirm tumor segmentation output is produced when tumor.segmentation.output is specified
- **With arguments.file**: Pass additional arguments and confirm GATK receives them
- **Error handling**: Test with missing/empty input files to confirm meaningful error messages
- **Exit code**: Test that non-zero GATK exit codes cause the wrapper to exit with the same code
