## 1. Tool Purpose & Scientific Applications

### Overview
`CalculateContamination` is a core component of the **GATK4 (Genome Analysis Toolkit v4)** suite, developed and maintained by the **Broad Institute**. It estimates the fraction of reads in a sequenced sample that originate from cross-sample contamination, given pileup data generated by the upstream `GetPileupSummaries` tool.

### Scientific Role
Cross-sample contamination is one of the most common sources of artifact mutations in somatic variant calling. Even low levels of contamination (1–5%) can generate spurious somatic calls. `CalculateContamination` quantifies this contamination fraction using a **binomial mixture model** applied to germline variant sites from population databases (e.g., gnomAD), enabling downstream filtering by `FilterMutectCalls`.

### Algorithm
The tool uses **maximum likelihood estimation (MLE)** over germline heterozygous and homozygous variant sites:
- At sites where a sample is **homozygous reference**: contamination introduces alternate-allele reads at a frequency ≈ contamination fraction × population alt frequency
- At sites where a sample is **homozygous alternate**: contamination introduces reference reads
- The model integrates these observations genome-wide to produce a single contamination fraction estimate and its standard error
- When tumor **segmentation** is also output, the model accounts for allelic imbalance across aneuploid regions

### Applications
| Application | Description |
|---|---|
| **Somatic QC** | Primary QC gate in GATK Best Practices somatic pipeline |
| **Sample swap detection** | High contamination (>10%) may indicate sample mislabeling |
| **Tumor purity estimation** | Segmentation output reflects minor allele fractions across the genome |
| **Clinical variant interpretation** | Clean contamination estimates are required for clinical-grade variant calls |
| **Population-scale cohort QC** | Batch assessment of sample quality across cancer cohorts |

"""
GenePattern Module Wrapper: gatk.CalculateContamination

Wraps the GATK4 CalculateContamination tool for cross-sample contamination
estimation. Supports both tumor-only and matched normal modes.

Author:    GenePattern Module Development
Tool:      GATK CalculateContamination (Broad Institute)

import logging
import os
import subprocess
import sys
from pathlib import Path

# ── Logging setup ──────────────────────────────────────────────────────────────
logging.basicConfig(
    level=logging.INFO,
    format="[%(asctime)s] %(levelname)s: %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
    stream=sys.stdout,

log = logging.getLogger(__name__)


# ── Helpers ────────────────────────────────────────────────────────────────────

def _resolve_gatk() -> str:
    """
    Locate the GATK executable.
    Search order:
      1. GATK_PATH environment variable (full path to 'gatk' script or JAR)
      2. 'gatk' on the PATH
      3. Common installation locations
    Returns the command prefix (e.g. 'gatk' or 'java -jar /path/to/gatk.jar').
    """
    # 1. Environment variable override
    gatk_env = os.environ.get("GATK_PATH", "").strip()
    if gatk_env:
        if gatk_env.endswith(".jar"):
            java_bin = os.environ.get("JAVA_HOME", "")
            java_cmd = os.path.join(java_bin, "bin", "java") if java_bin else "java"
            log.info("Using GATK JAR (from GATK_PATH): %s", gatk_env)
            return f"{java_cmd} -jar {gatk_env}"
        else:
            log.info("Using GATK executable (from GATK_PATH): %s", gatk_env)
            return gatk_env

    # 2. 'gatk' on PATH
    import shutil
    if shutil.which("gatk"):
        log.info("Using 'gatk' found on PATH.")
        return "gatk"

    # 3. Common fallback locations
    fallbacks = [
        "/opt/gatk/gatk",
        "/usr/local/bin/gatk",
        "/gatk/gatk",           # Docker image default
    ]
    for path in fallbacks:
        if os.path.isfile(path):
            log.info("Using GATK at fallback path: %s", path)
            return path

    raise FileNotFoundError(
        "GATK executable not found. Set the GATK_PATH environment variable "
        "to the full path of the 'gatk' wrapper script or the GATK JAR file."
    )


def _validate_input_file(filepath: str, label: str) -> Path:
    """Validate that a required input file exists and is non-empty."""
    p = Path(filepath)
    if not p.exists():
        log.error("%s not found: %s", label, filepath)
        sys.exit(1)
    if p.stat().st_size == 0:
        log.error("%s is empty: %s", label, filepath)
        sys.exit(1)
    log.info("Validated %s: %s", label, p.resolve())
    return p


def _validate_optional_file(filepath: str | None, label: str) -> Path | None:
    """Validate an optional input file if it was provided."""
    if not filepath:
        return None
    return _validate_input_file(filepath, label)


def _ensure_output_dir(filepath: str) -> None:
    """Create parent directories for an output file path if they don't exist."""
    parent = Path(filepath).parent
    if parent and not parent.exists():
        log.info("Creating output directory: %s", parent)
        parent.mkdir(parents=True, exist_ok=True)


def _run_command(cmd: list[str]) -> int:
    """
    Execute a shell command, streaming stdout/stderr to the logger.
    Returns the exit code.
    """
    cmd_str = " ".join(cmd)
    log.info("Running command:\n  %s", cmd_str)
    print(f"\n{'='*72}", flush=True)
    print(f"COMMAND: {cmd_str}", flush=True)
    print(f"{'='*72}\n", flush=True)

    proc = subprocess.Popen(
        cmd,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        text=True,
        bufsize=1,
    )
    assert proc.stdout is not None
    for line in proc.stdout:
        print(line, end="", flush=True)
    proc.wait()
    return proc.returncode

# ── Command builder ────────────────────────────────────────────────────────────

def _build_gatk_command(
    gatk_cmd: str,
    tumor_pileup_input: str,
    output: str,
    matched_normal_input: str | None,
    tumor_segmentation_output: str | None,
    arguments_file: str | None,
) -> list[str]:
    """
    Assemble the full GATK CalculateContamination command as a list of tokens.
    The gatk_cmd may be a multi-word string (e.g. 'java -jar /path/to/gatk.jar'),
    which is why we split it.
    """
    cmd = gatk_cmd.split() + ["CalculateContamination"]

    # Required
    cmd += ["-I", tumor_pileup_input]
    cmd += ["-O", output]

    # Matched normal (optional) — triggers matched-normal mode
    if matched_normal_input:
        cmd += ["-matched", matched_normal_input]

    # Tumor segmentation output (optional)
    if tumor_segmentation_output:
        cmd += ["--tumor-segmentation", tumor_segmentation_output]

    # Additional arguments file (optional)
    if arguments_file:
        cmd += ["--arguments_file", arguments_file]

    return cmd


# ── Main entrypoint ────────────────────────────────────────────────────────────

def main(argv: list[str] | None = None) -> None:
    parser = _build_arg_parser()
    args = parser.parse_args(argv)

    log.info("=" * 72)
    log.info("gatk.CalculateContamination — GenePattern Module Wrapper")
    log.info("=" * 72)

    # ── Determine operating mode ─────────────────────────────────────────────
    mode = "MATCHED NORMAL" if args.matched_normal_input else "TUMOR-ONLY"
    log.info("Operating mode: %s", mode)

    # ── Validate inputs ───────────────────────────────────────────────────────
    _validate_input_file(args.tumor_pileup_input, "Tumor pileup summary")
    _validate_optional_file(args.matched_normal_input, "Matched normal pileup summary")
    _validate_optional_file(args.arguments_file, "Additional arguments file")

    # ── Ensure output directories exist ──────────────────────────────────────
    _ensure_output_dir(args.output)
    if args.tumor_segmentation_output:
        _ensure_output_dir(args.tumor_segmentation_output)

    # ── Locate GATK ──────────────────────────────────────────────────────────
    try:
        gatk_cmd = _resolve_gatk()
    except FileNotFoundError as exc:
        log.error(str(exc))
        sys.exit(1)

    # ── Build and run command ─────────────────────────────────────────────────
    cmd = _build_gatk_command(
        gatk_cmd=gatk_cmd,
        tumor_pileup_input=args.tumor_pileup_input,
        output=args.output,
        matched_normal_input=args.matched_normal_input,
        tumor_segmentation_output=args.tumor_segmentation_output,
        arguments_file=args.arguments_file,
    )

    exit_code = _run_command(cmd)

    # ── Post-run validation ───────────────────────────────────────────────────
    if exit_code != 0:
        log.error("GATK CalculateContamination failed with exit code %d.", exit_code)
        sys.exit(exit_code)

    log.info("GATK CalculateContamination completed successfully.")

    # ── Report outputs ────────────────────────────────────────────────────────
    _report_output(args.output, "Contamination table")
    if args.tumor_segmentation_output:
        _report_output(args.tumor_segmentation_output, "Tumor segmentation table")

    log.info("=" * 72)
    log.info("Module execution complete.")
    log.info("=" * 72)


def _report_output(filepath: str, label: str) -> None:
    """Log a summary of a produced output file."""
    p = Path(filepath)
    if p.exists() and p.stat().st_size > 0:
        # Show the first few lines for user feedback
        try:
            with open(p) as fh:
                header = fh.readline().strip()
                first_data = fh.readline().strip()
            log.info(
                "%s written: %s  (%d bytes)",
                label, p.resolve(), p.stat().st_size,
            )
            log.info("  Header : %s", header)
            if first_data:
                log.info("  Row 1  : %s", first_data)
        except Exception:
            log.info("%s written: %s", label, p.resolve())
    else:
        log.warning(
            "%s not found or empty after execution: %s", label, filepath
        )


if __name__ == "__main__":
    main()

## 9. Known Limitations & Caveats

| Issue | Description | Mitigation |
|---|---|---|
| **Input dependency** | Requires pileup summaries from `GetPileupSummaries`; generic pileup formats not accepted | Always run GetPileupSummaries first |
| **Reference panel sensitivity** | Accuracy depends on quality of germline resource used in GetPileupSummaries | Use high-quality panel (e.g., gnomAD) |
| **Low coverage** | Sparse pileup tables (few sites) reduce estimation accuracy | Ensure adequate read depth and broad interval list |
| **Tumor-only accuracy** | Less accurate than matched-normal mode for distinguishing germline from contamination | Use matched normal whenever possible |
| **Highly aneuploid tumors** | Extreme copy number changes can bias tumor-only estimates | Use `--tumor-segmentation` output for `FilterMutectCalls` |
| **FFPE samples** | Oxidative damage artifacts may inflate contamination estimate | Use strand-specific filters and FFPE-aware variant calling |
